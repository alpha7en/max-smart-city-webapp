## 1. Назначение решения

«MAX Умный Дом» устраняет главные боли жителей и управляющих компаний:
- **Ликвидация ручного ввода и ошибок в 1000 раз:** автоматическое отсечение красных роликов (литров) при сканировании счетчиков воды и газа;
- **Мгновенная сдача показаний через чат:** возможность просто переслать фото счетчика из любого семейного чата в бот — без необходимости вводить логины и пароли;
- **«Зеленый Щит Безопасности» (Анти-мошенник):** сверка заводского номера со ФГИС «АРШИН» Росстандарта для защиты жителей от спам-листовок с угрозами штрафов (экономия 5 000 – 10 000 руб. на семью);
- **Прозрачная оплата по ГОСТ Р 56042-2014:** сплитование единого платежа по 103-ФЗ и 59-ФЗ на специальный счет 40821 (деньги уходят напрямую Водоканалу, МОЭК, Энергосбыту и УК, защищены от долгов УК);
- **Гостевой доступ для арендаторов:** сдача показаний и оплата без входа через Госуслуги (ЕСИА) и без доступа к личным документам собственника;
- **АРМ Обходчика УК с ЭЦП (63-ФЗ):** мобильный инструмент контролера для формирования юридически значимых цифровых актов с GPS-меткой, таймстемпом и SHA-256 хэшем для выгрузки в 1С:ЖКХ;
- **Персистентность данных (SQLite WAL):** сохранение состояния профилей, адресов, приборов, показаний и заявок в томе данных (`./data:/app/data`) между перезапусками.

## 5. Персистентное хранилище (SQLite WAL)

В платформе реализован легковесный персистентный слой данных на стандартном `sqlite3` без добавления тяжелых внешних pip-зависимостей:

- **Файл базы данных**: `data/smart_city.db` (при запуске в Docker монтируется том `./data:/app/data`);
- **Режим WAL (Write-Ahead Logging)**:
  ```sql
  PRAGMA journal_mode=WAL;
  PRAGMA synchronous=NORMAL;
  PRAGMA busy_timeout=5000;
  PRAGMA foreign_keys=ON;
  ```
  Обеспечивает параллельное неблокирующее чтение при одновременной записи из FastAPI и фонового воркера Long Polling.
- **Таблицы схемы**:
  1. `users`: идентификатор, телефон, имя, активный адрес, отметка верификации;
  2. `properties`: привязка адресов МКД к ЕЛС ГИС ЖКХ и управляющей компании;
  3. `meters`: приборы учета (ХВС, ГВС, свет, газ, тепло), межповерочные интервалы, единицы учета;
  4. `meter_readings`: история переданных показаний, расход, флаги аномалий и каналы сдачи;
  5. `tickets`: аварийные заявки по ПП РФ № 40 со статусами и SLA;
  6. `inspector_acts`: оформленные электронные акты осмотра с GPS и SHA-256.
- **Автоматический сидинг**: при первом запуске база автоматически наполняется эталонными данными жителя Иванова И. И., двух адресов и пяти приборов учета.

## 6. Запуск через Docker одной командой

Для развертывания всех компонентов решения выполните:

```bash
docker compose up --build
```
*(Время сборки: **~25–30 секунд**, лимит по регламенту хакатона — до 5 минут).*

После запуска доступны:
- Мини-приложение: `http://localhost:8080`
- Документация API Swagger: `http://localhost:8080/docs`
- Проверка здоровья сервиса: `http://localhost:8080/api/health`
- База данных SQLite сохраняется на хосте в каталоге `./data/smart_city.db`.
- Бот в MAX автоматически подключается и слушает события (при наличии `BOT_TOKEN`).

## 9. Пошаговый сценарий проверки для жюри (Jury Quickstart)

### Вариант А: Интерактивная проверка в мессенджере MAX
1. Откройте мессенджер MAX, найдите бота **`@t226_hakaton_max_bot`**;
2. Нажмите кнопку **«Начать»** или отправьте `/start`;
3. Нажмите кнопку **«Мини-приложение»** для запуска интерфейса в нативном окне WebView;
4. Перешлите любое фото счетчика прямо в чат — бот мгновенно распознает показания, отсечет красные литры, проверит поверку во ФГИС «АРШИН» и предложит подтвердить передачу в 1 клик;
5. Проверьте антифрод: введите `поверка 2809142` — бот выдаст «Зеленый Щит Безопасности».

### Вариант Б: Проверка через Мини-приложение в браузере
1. Откройте в браузере `http://localhost:8080`;
2. Во вкладке **«Счетчики»** нажмите «Камера AI» — откроется интерактивный видоискатель с прицельной рамкой, углом наклона и фонариком;
3. Нажмите «Сделать снимок» — симулируется AI-распознавание с механическим счетчиком и автоматическим отсечением красных роликов (литров);
4. Во вкладке **«Антифрод»** воспользуйтесь быстрыми кнопками: проверьте действующий прибор (№ 2809142), просроченный (№ 991201) или фальшивку (№ 000000);
5. Во вкладке **«Оплата»** нажмите «Вставить образец квитанции» и «Оплатить через СБП» — сформируется официальный фискальный чек со сплитованием на спецсчет 40821 (103-ФЗ);
6. Во вкладке **«Заявки»** создайте обращение в аварийно-диспетчерскую службу по ПП РФ № 40 или скопируйте гостевой доступ для арендатора в 1 клик;
7. Во вкладке **«Обходчик»** нажмите «Сформировать цифровой акт с ЭЦП» — генерируется юридически значимый акт контрольного осмотра с GPS-привязкой, таймстемпом и SHA-256 хэшем.
