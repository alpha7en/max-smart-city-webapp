## 1. Назначение решения

«MAX Умный Дом» устраняет главные боли жителей и управляющих компаний:
- **Ликвидация ручного ввода и ошибок в 1000 раз:** автоматическое отсечение красных роликов (литров) при сканировании счетчиков воды;
- **Мгновенная сдача показаний через чат:** возможность просто переслать фото счетчика из любого семейного чата в бот — без необходимости вводить логины и пароли;
- **«Зеленый Щит Безопасности» (Анти-мошенник):** сверка заводского номера со ФГИС «АРШИН» Росстандарта для защиты жителей от спам-листовок с угрозами штрафов (экономия 5 000 – 10 000 руб. на семью);
- **Прозрачная оплата по ГОСТ Р 56042-2014:** сплитование единого платежа по 103-ФЗ и 59-ФЗ на специальный счет 40821 (деньги уходят напрямую Водоканалу, МОЭК, Энергосбыту и УК, защищены от долгов УК);
- **«Ночной дозор» (Крауд-диагностика небаланса ОДПУ):** локализация ночных утечек в стояках МКД жителями за 30-секундный «Тест салфетки» со скидкой 10% на квартплату;
- **Гостевой доступ для арендаторов:** сдача показаний и оплата без входа через Госуслуги (ЕСИА) и без доступа к документам собственника.

## 3. Состав и архитектура решения

- **Backend / API:** Python 3.11, FastAPI, Pydantic v2, Uvicorn, PyYAML;
- **MAX Bot Service:** Асинхронный Long Polling / Webhook воркер для платформы `https://platform-api2.max.ru`;
- **Frontend Mini-App:** SPA на базе HTML5, JavaScript и CSS, стилизованный по гайдлайнам MAX UI, подключенный к `window.WebApp` (MAX Bridge);
- **Доменные сервисы:**
  - `MeterService` — бизнес-валидация, монотонность, фильтр барабанов;
  - `ArshinService` — интеграция с реестром Росстандарта и антифрод;
  - `GostQrService` — парсер/генератор ГОСТ Р 56042-2014, сплит на счет 40821;
  - `NightFlowService` — алгоритм поиска ночного небаланса ОДПУ (261-ФЗ);
  - `TicketService` — диспетчерская служба по ПП РФ № 40 (SLA 30 мин / 24 ч);
  - `GuestAccessService` — выпуск гостевых токенов для арендаторов;
  - `AiVisionService` [ЗАГЛУШКА / STUB] — эмуляция детекции и OCR.

## 8. Внешние сервисы и интеграции

1. **MAX Platform API (`https://platform-api2.max.ru`):**
   - Получение апдейтов через Long Polling (`GET /updates`) или Webhook (`POST /subscriptions`);

   - Открытый федеральный реестр метрологических поверок (102-ФЗ).
4. **ГИС ЖКХ / 1С:ЖКХ [MOCK / STUB]:**
   - Эмуляция SOAP WSDL `hcs-device-meterings` для регистрации показаний в ЕЛС.
5. **Банковский эквайринг СБП [MOCK / STUB]:**
   - Эмуляция моментального расщепления на спецсчет 40821 по 103-ФЗ.

## 9. Описание работы с данными

- **Приборы учета:** идентификатор, тип ресурса, заводской номер, дата и значение предыдущих показаний, срок действия поверки, разрядность красных роликов.
- **Показания:** валидация типа `float`, проверка монотонности (`val >= prev`), проверка верхнего порога всплеска потребления.
- **Платежи:** соответствие стандарту ГОСТ Р 56042-2014, проверка контрольного ключа расчетного счета по правилам ЦБ РФ, автоматический расчет долей РСО (Водоканал, МОЭК, Энергосбыт, УК).

## 12. Примеры ожидаемого поведения системы

- **Ввод 8 цифр `142789` на счетчике воды:** система отсекает красные литры `789` и фиксирует показание `142.0 м³`, предотвращая завышение счета в 1000 раз.
- **Ввод значения меньше предыдущего (`120 < 142`):** система блокирует запись и выдает предупреждение: *«Ошибка монотонности: новое значение меньше предыдущего»*.
- **Проверка номера `2809142`:** выдается «Зеленый Щит Безопасности»: *«Прибор ИТЭЛМА № 2809142 поверен до 18.10.2029 г. Поверка НЕ ТРЕБУЕТСЯ еще 3 года. Листовки в почтовом ящике — мошенничество!»*.

## 13. Известные ограничения

- **[ЗАГЛУШКА / MOCK] Детекция и OCR по фото:** тяжелые веса YOLOv8 и OCR-пайплайна заменены детерминированным микросервисом-заглушкой `AiVisionService` во избежание многогигабайтных зависимостей и обеспечения сборки Docker < 30 секунд.
- **Интеграция с ГИС ЖКХ:** тестовый стенд эмулирует прием SOAP WSDL сообщений `importMeteringDeviceValues`, так как промышленный контур ЕСИА требует защищенного VPN-канала ГОСТ TLS.
