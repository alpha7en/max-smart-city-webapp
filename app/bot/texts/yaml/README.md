# Тексты бота

Здесь все сообщения и подписи кнопок бота и сообщения об ошибках мини-приложения. Файлы можно править прямо
на GitHub (карандаш «Edit file»). Код берёт строку по ключу (`ASK_NAME: …`), поэтому менять можно только текст
справа от двоеточия.

| Файл | Что внутри |
|---|---|
| `common.yaml` | приветствие, общие ошибки и кнопки («Назад», «В меню», «Отмена»), слова «меню» и «отмена» |
| `registration.yaml` | регистрация: ФИО, телефон, адрес, квартира, сводка |
| `submission.yaml` | подача показаний: фото, распознавание, номер, проверка, ручной ввод, «Готово», ошибки ввода |
| `menu.yaml` | меню-дашборд, «Мои счётчики», заглушки оплаты и поверки |
| `meters.yaml` | карточка счётчика и его удаление |
| `profile.yaml` | профиль, «нет прав», запрос доступа у собственника, удаление данных |
| `sharing.yaml` | «Поделиться доступом», «Общий доступ», ссылки-приглашения |
| `notify.yaml` | уведомления о подаче, поверке, счёте и команда `/demo` |
| `verification.yaml` | поверка по ФГИС «Аршин» |
| `api.yaml` | ошибки мини-приложения и подтверждение подачи в чат |
| `hackathon_demo.yaml` | только для хакатона: `/demo_profile` |

## Правила

- **Подстановки в фигурных скобках** (`{name}`, `{date}`, `{amount}`, `{address}`…) заполняет код. Их нельзя
  удалять и переименовывать, можно переставлять и менять слова вокруг.
- **Длина кнопок** (ключи `BTN_*`): обычные — до 24 символов, срочные — до 32, счётчики и адреса — до 40.
  Длиннее MAX обрежет подпись многоточием; длиннее 128 символов бот не сможет отправить сообщение.
- **Стиль:** от сервиса — «мы», к пользователю — «вы». Не длиннее 8 строк. Без эмодзи, без канцелярита
  («данный», «успешно», «осуществляется»), без капса (кроме «ПРИШЛИТЕ ВАШЕ ФОТО В ЧАТ»), без ссылок в тексте —
  ссылки только кнопками (исключение — ссылка-приглашение `LINK`, её пересылают целиком).
- **Разметка:** `**жирный**` — показания, суммы, даты, сроки (1–3 места на сообщение). Демо-оговорки —
  последней строкой-цитатой `> …` после пустой строки; у большинства сообщений её добавляет код.
- **Многострочный текст** — блок `|-`: строки с отступом в два пробела, пустая строка — новый абзац.

## Проверка

```bash
python -m pytest -q tests/test_texts_integrity.py
```

Тест проверяет, что YAML читается и все ключи, которые использует код, на месте. Длину кнопок и стиль тест
не проверяет. Новый ключ появляется в YAML вместе с кодом, который его использует (`app/bot/texts/<файл>.py`).
