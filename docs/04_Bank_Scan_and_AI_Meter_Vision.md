# Компьютерное зрение в ЖКХ: Сканирование платежек и распознавание счетчиков (Сбер, Т-Банк, ВТБ, Smart Engines)

---

## 1. Как банки сканируют платежки: Два технологических стека

### Стек А: Сканирование по QR-коду (ГОСТ Р 56042-2014)
- **Используется**: Во всех банках РФ (Сбер, Т-Банк, ВТБ, Альфа-Банк, Газпромбанк).
- **Как работает**:
  1. Камера устройства захватывает кадр;
  2. Библиотека компьютерного зрения (zxing / on-device barcode detector) находит маркеры позиционирования QR-кода;
  3. Декодируется текстовая строка;
  4. Проверяется сигнатура `ST00011` / `ST00012` и разделитель `|`;
  5. Проверяется 9-й контрольный разряд расчетного счета по весовым коэффициентам ЦБ РФ;
  6. Данные мгновенно подставляются в платежное поручение.

### Стек Б: Интеллектуальное сканирование квитанций БЕЗ QR-кода (Умная камера)
- **Внедрено**: В Т-Банке («Умная камера»), ВТБ Онлайн, СберБизнес.
- **Технологические провайдеры**:
  - **Smart Engines** (Россия): библиотека **Smart Document Engine / Smart Code Engine**.
    - Архитектура: легковесные сверточные нейросети, скомпилированные в C++ / WebAssembly / Apple Neural Engine;
    - Скорость: **до 0.1 секунды на кадр**;
    - Работает **локально (on-device)** на процессоре смартфона без отправки фото в облако (соответствие 152-ФЗ).
  - **Алгоритм**:
    1. Детекция границ документа в видеопотоке (Document Quad Detection);
    2. Проективное выравнивание (Homography transform);
    3. Выделение зон текста (Text block detection);
    4. Поиск якорных лексем («ИНН», «КПП», «Получатель», «Счет», «БИК», «Итого к оплате»);
    5. Извлечение сущностей (Key Information Extraction) и математическая проверка контрольных сумм ИНН/БИК/счетов.

## 2. Как устроен функционал Сбера по распознаванию счетчиков по фото

### 2.1. Официальные факты и характеристики решения Сбера
- **Разработчик**: Центр искусственного интеллекта (ЦИИ) блока «Сервисы» Сбербанка.
- **Заявленная точность**: **97%**.
- **Типы приборов**: Счетчики холодной (ХВС) и горячей (ГВС) воды подавляющего большинства производителей (Itelma, Valtec, Бетар, Метер, Норма, Декаст).
- **Сценарий пользователя в «СберБанк Онлайн»**:
  1. Раздел «Платежи» ➔ «Дом» / «ЖКХ» ➔ выбор поставщика или сохраненного адреса;
  2. Нажатие иконки фотокамеры в поле ввода показаний («Сфотографировать счетчик»);
  3. Возможность сделать живой снимок или **загрузить фото из галереи** (важно для тех, кому фото прислали арендаторы или родственники);
  4. Модель распознает цифры и автоматически заполняет поле;
  5. Пользователь проверяет и подтверждает передачу показаний.

### 2.2. Архитектура open-source фреймворка TorchOk (EORA / экосистема Sber AI)
В открытых публикациях Сбер AI и партнерских команд (EORA) на Habr («TorchOk — представляем open-source пайплайн для обучения нейросетей») детально разобран пайплайн распознавания аналоговых и цифровых счетчиков:

```text
               [Входное изображение счетчика]
                             │
                             ▼
┌─────────────────────────────────────────────────────────────┐
│ Этап 1: ДЕТЕКЦИЯ ПРИБОРА И ЦИФЕРБЛАТА (Detection)           │
│ - Модель: YOLOv8-nano / Faster R-CNN                        │
│ - Находит Bounding Box циферблата (Dial Box)                │
│ - Выравнивает наклон и перспективу (Perspective Transform)  │
└────────────────────────────┬────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────┐
│ Этап 2: ВЫДЕЛЕНИЕ ЗОНЫ РОЛИКОВ И ЦВЕТОВАЯ СЕГМЕНТАЦИЯ      │
│ - Модель сегментации: U-Net / MobileNet                     │
│ - КРИТИЧЕСКИЙ ШАГ: Разделение роликов на:                   │
│   * ЧЕРНАЯ ЗОНА (5 роликов) = Целые кубометры (м³)         │
│   * КРАСНАЯ ЗОНА (3 ролика) = Литры / тысячные доли м³      │
└────────────────────────────┬────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────┐
│ Этап 3: OCR РАСПОЗНАВАНИЕ ЦИФР (Digit Recognition)          │
│ - CRNN + CTC Loss или классификатор отдельных разрядов      │
│ - Обработка краевого случая "полуоборота" (Half-turn roll): │
│   когда цифра смещается в барабане (напр. между 3 и 4)      │
└────────────────────────────┬────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────┐
│ Этап 4: БИЗНЕС-ВАЛИДАЦИЯ (Sanity Check)                     │
│ - V_текущее >= V_предыдущее                                 │
│ - 0 <= (V_тек - V_пред) <= Порог (например, 40-50 кубов)    │
│ - Защита от переполнения / аномалий                         │
└─────────────────────────────────────────────────────────────┘
```

## 3. Решение ВТБ Онлайн и Smart Engines (Электросчетчики)
- В приложении «ВТБ Онлайн» совместно со **Smart Engines** и **АО «Мосэнергосбыт»** внедрено on-device сканирование счетчиков электроэнергии.
- Особенности:
  - Распознавание в реальном времени при наведении камеры (без нажатия кнопки спуска);
  - Поддержка многотарифных счетчиков (Т1 — День, Т2 — Ночь, Т3 — Полупик);
  - Работает как с механическими барабанами, так и с жидкокристаллическими (LCD) экранами.
