# Пример диалога с ботом

Сгенерировано командой `python -m tools.transcript > docs/dialog-example.md`: сообщения прошли через настоящий роутер бота, вместо MAX — тестовый двойник. Дата — 19 октября 2026, окно подачи открыто. Без ключа DaData адрес разбирается локально, без `RECOGNIZER_URL` цифры подставляет демо-распознавание, а срок поверки берётся из демо-данных ФГИС «Аршин» (ARSHIN_MODE=fixtures; номер на «0» — записи нет). Кнопки показаны как `[Текст]`, ряды разделены переносом.
