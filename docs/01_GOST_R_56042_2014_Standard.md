# ГОСТ Р 56042-2014: Стандарты финансовых операций. Двумерные символы штрихового кода для осуществления платежей физических лиц

**Статус документа**: Национальный стандарт Российской Федерации
**Дата введения**: 2015-01-01 (актуален, действует повсеместно в банковской системе РФ)
**Разработчик**: Некоммерческое партнерство «Национальный платежный совет» (НП «НПС») совместно со Сбербанком России
**Утвержден**: Приказом Росстандарта от 11.06.2014 № 552-ст
**Официальный первоисточник**: Электронный фонд нормативно-технической документации [docs.cntd.ru/document/1200111520](https://docs.cntd.ru/document/1200111520)

---

## 1. Назначение и сфера применения стандарта
Стандарт определяет единый формат данных для формирования двумерных штриховых кодов (QR-кодов) в платежных документах (квитанциях ЖКХ, налогах, штрафах ГИБДД, счетах за обучение).
Благодаря этому клиент любого банка (Сбер, Т-Банк, ВТБ, Альфа-Банк) наводит камеру смартфона на платежку, и приложение мгновенно считывает реквизиты без ручного ввода.

---

## 2. Структура строки данных (Спецификация)
Строка представляет собой набор текстовых пар `ИмяТега=Значение`, разделенных символом `|`.

### 2.1. Служебный заголовок
- `ST00011` — кодировка Windows-1251 (CP1251);
- `ST00012` — кодировка UTF-8.

### 2.2. Обязательные реквизиты (Служебный блок)
Каждый валидный платежный QR-код обязан содержать 5 полей:
1. `Name` — Наименование получателя (УК, ТСЖ, РСО, ЕИРЦ);
2. `PersonalAcc` — Номер расчетного счета получателя (20 цифр);
3. `BankName` — Наименование банка получателя;
4. `BIC` — БИК банка (9 цифр, начинается на 04);
5. `CorrespAcc` — Корреспондентский счет банка в ЦБ РФ (20 цифр, начинается на 30101).

### 2.3. Дополнительные реквизиты для сферы ЖКХ
- `Sum` — Сумма платежа **в копейках** (целое число, напр. 543020 = 5430 руб. 20 коп.);
- `Purpose` — Назначение платежа;
- `PayeeINN` — ИНН получателя (10 цифр для юрлиц);
- `KPP` — КПП получателя (9 цифр);
- `PersAcc` — Номер лицевого счета абонента в биллинге;
- `PaymPeriod` — Расчетный период в формате ММГГГГ (напр. 082026);
- `PayerAddress` — Адрес плательщика;
- `TechCode` — Код услуги (01 — ЖКУ, 02 — газ, 03 — электроэнергия, 04 — водоснабжение, 05 — отопление, 06 — капремонт);
- `ELS` — Единый лицевой счет в ГИС ЖКХ (10 знаков).

## 3. Эталонный пример строки платежа ЖКХ
```text
ST00012|Name=ООО "УК ДОМ-СЕРВИС"|PersonalAcc=40821810338000005432|BankName=ПАО СБЕРБАНК|BIC=044525225|CorrespAcc=30101810400000000225|PayeeINN=7701987654|KPP=770101001|Sum=725040|Purpose=Оплата за ЖКУ за 08.2026 ЛС 7701234567|PersAcc=7701234567|PaymPeriod=082026|PayerAddress=г. Москва, ул. Тверская, д. 10, кв. 24|LastName=Иванов|FirstName=Сергей|MiddleName=Алексеевич|TechCode=01
```
Счет `40821...` — это спецсчет платежного агента по 103-ФЗ!
