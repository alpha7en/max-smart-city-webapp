## 2. Набор автоматических тестов (`tests/test_all_scenarios.py`)

Для независимой и объективной верификации работы системы разработан сквозной набор тестов:

1. **Тест 1: Валидация API-профиля бота (`GET /me`)**:
   - Проверка доступности серверов MAX `platform-api2.max.ru`.
   - Проверка корректности авторизации токеном.
2. **Тест 2: CV Pipeline распознавания приборов учета (`POST /api/meter/scan`)**:
   - Эмуляция фото счетчика холодной воды (ХВС): проверка парсинга кубов и литров (`142.385`).
   - Эмуляция фото двухтарифного электросчетчика (Т1 день / Т2 ночь): расчет раздельных показателей.
   - Проверка защиты от аномалий (превышение расхода > 300% генерирует `anomaly_warning`).
3. **Тест 3: Верификатор ФГИС «АРШИН» (`GET /api/arshin/verify`)**:
   - Проверка валидного счетчика (поверка действует до 2029 года -> статус `SAFE_GREEN_SHIELD`).
   - Проверка счетчика с истекшим сроком поверки -> статус `EXPIRED_WARNING`.
4. **Тест 4: Парсер QR-квитанций ЖКХ по ГОСТ Р 56042-2014 (`POST /api/qr/parse`)**:
   - Разбор строки стандарта `ST00012|Name=...|PersonalAcc=...|Sum=...`.
   - Проверка контрольной суммы и выделения реквизитов УК и лицевого счета.
5. **Тест 5: Модуль «Ночной дозор» (`POST /api/odpu/night-patrol`)**:
   - Расчет ночного небаланса ОДПУ подъезда (разница нормативного микрорасхода и реального ночного потока).
   - Формирование карточки экспресс-диагностики с салфеткой.
6. **Тест 6: Цифровой акт обходчика УК (`POST /api/uk/inspector-act`)**:
   - Формирование криптографического SHA-256 хеша фото, привязка GPS и таймстемпа.

## 3. Сценарий ручной проверки для членов жюри (Walkthrough)

1. **Шаг 1: Запуск контейнера**:
   ```bash
   docker compose up --build -d
   ```
2. **Шаг 2: Проверка веб-интерфейса**:
   - Открыть в браузере `http://localhost:8000`.
   - Проверить переключение вкладок: **«📷 Сканер счетчика»**, **«🛡️ Зеленый Щит (АРШИН)»**, **«🌙 Ночной дозор»**, **«🔑 Арендатор»**, **«📋 Обходчик УК»**.
3. **Шаг 3: Проверка бота в мессенджере MAX**:
   - Найти бота `@t226_hakaton_max_bot` в мессенджере MAX.
   - Нажать **«Начать»** (`/start`) -> бот присылает меню с кнопками.
   - Отправить любое фото счетчика прямо в чат -> бот мгновенно возвращает карточку распознавания и статус проверки поверки.
