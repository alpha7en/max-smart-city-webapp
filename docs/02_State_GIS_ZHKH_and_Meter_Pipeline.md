# Государственная архитектура ЖКХ: Единая система, Реестры и Передача показаний (ГИС ЖКХ и Госуслуги Дом)

**Нормативно-правовая база**:
1. **Федеральный закон от 21.07.2014 № 209-ФЗ** «О государственной информационной системе жилищно-коммунального хозяйства» ([КонсультантПлюс](http://www.consultant.ru/document/cons_doc_LAW_165902/)).
2. **Постановление Правительства РФ от 06.05.2011 № 354** «О предоставлении коммунальных услуг собственникам и пользователям помещений в многоквартирных домах и жилых домов» ([КонсультантПлюс](http://www.consultant.ru/document/cons_doc_LAW_114247/)).
3. **Федеральный закон от 26.06.2008 № 102-ФЗ** «Об обеспечении единства измерений» (ФГИС «АРШИН», реестр Росстандарта).

---

## 1. Есть ли единая государственная система?
**Да, единая государственная система существует — это ГИС ЖКХ ([dom.gosuslugi.ru](https://dom.gosuslugi.ru)).**
- **Кураторы**: Минстрой России и Минцифры России.
- **Оператор**: АО «Оператор информационной системы» (АО «Оператор ИС»).
- **Обязанность**: Все управляющие организации (УК, ТСЖ), ресурсоснабжающие организации (РСО), региональные операторы ТКО, расчетные центры обязаны по закону выгружать данные в ГИС ЖКХ. За неразмещение — штрафы по ст. 13.19.1 и 13.19.2 КоАП РФ.

### Мобильный фронтенд государства: Приложение «Госуслуги Дом»
- Запущено Минстроем и Минцифры на базе ГИС ЖКХ (разработчик — VK / АО «Оператор ИС»).
- Авторизация через подтвержденную запись ЕСИА (Госуслуги).
- Автоматически подтягивает всю недвижимость пользователя из Росреестра и ГИС ЖКХ.
- Функции: передача показаний счетчиков, оплата без комиссии через СБП, заявки в УК, общедомовые собрания.

## 2. Единые сквозные идентификаторы ГИС ЖКХ
1. **ЕЛС (Единый лицевой счет)** — 10-значный номер (напр. `10АА123456`), закрепленный за помещением и плательщиком на территории всей России.
2. **ИЖКУ (Идентификатор жилищно-коммунальной услуги)** — привязан к конкретному поставщику ресурса/услуги в рамках ЕЛС.
3. **Идентификатор ПД (Платежного документа)** — уникальный номер начисления/квитанции.
4. **Номер ПУ (Прибора учета)** — уникальный номер счетчика в федеральном реестре.

## 3. Куда идут данные со счетчиков: 4 основные схемы маршрутизации

### Схема 1: Традиционная через Управляющую компанию (УК/ТСЖ)
`Пользователь -> Приложение/сайт УК -> Биллинг УК (1С:ЖКХ / Инфокрафт) -> Начисление -> ГИС ЖКХ`
Пользователь передает данные в УК, УК рассчитывает сумму по тарифам и обязана экспортировать показания и начисления в ГИС ЖКХ.

### Схема 2: Прямые договоры с РСО (ст. 157.2 ЖК РФ, закон № 59-ФЗ)
Собственники на общем собрании исключили УК из цепочки коммунальных ресурсов. Показания передаются **напрямую каждому поставщику**:
- Холодная вода ➔ МУП «Водоканал»
- Горячая вода и отопление ➔ ПАО «МОЭК» / «Т Плюс»
- Электроэнергия ➔ АО «Мосэнергосбыт» / ПСК
- Газ ➔ ООО «Газпром межрегионгаз»

### Схема 3: «Единое окно» через «Госуслуги Дом» / ГИС ЖКХ
`Пользователь -> «Госуслуги Дом» -> SOAP API ГИС ЖКХ -> Маршрутизация по ИЖКУ поставщикам`
ГИС ЖКХ автоматически распределяет показания тем организациям, которые назначены исполнителями коммунальных услуг по данному дому.

### Схема 4: Региональные расчетные центры (ЕИРЦ)
В крупных регионах (Москва mos.ru, МосОблЕИРЦ, ЕИРЦ СПб) житель передает показания через региональный портал. Региональный биллинг рассчитывает единую квитанцию (ЕПД) и синхронизирует данные с федеральной ГИС ЖКХ через шлюзы интеграции.

## 4. Сроки и последствия непередачи показаний (Правила № 354)
- Рекомендуемый период: **с 15 по 25 число месяца**.
- Если не передавать:
  - 1–3 месяц: расчет по **среднемесячному потреблению** за предыдущие 6 месяцев (п. 59).
  - С 4-го месяца: расчет по **нормативу потребления** с повышающим коэффициентом 1.5 (п. 60).

---

## 5. Поверка счетчиков: ФГИС «АРШИН» (102-ФЗ)
С сентября 2020 года бумажные свидетельства о поверке отменены. Юридическую силу имеет только электронная запись во **ФГИС «АРШИН»** (реестр Росстандарта: `fgis.gost.ru`). Биллинги УК и ГИС ЖКХ проверяют срок поверки счетчика. Если срок истек — счетчик блокируется в системе.

## 6. Технический API ГИС ЖКХ: Спецификация SOAP WSDL
Для автоматизированного обмена показаниями ГИС ЖКХ использует защищенный веб-сервис:
- **WSDL-сервис**: `hcs-device-meterings`
- **Ключевой метод импорта показаний**: `importMeteringDeviceValues`
- **Ключевой метод экспорта истории**: `exportMeteringDeviceHistory`

### Пример фрагмента SOAP XML запроса:
```xml
<soapenv:Envelope xmlns:soapenv="http://schemas.xmlsoap.org/soap/envelope/"
                  xmlns:dev="http://dom.gosuslugi.ru/schema/integration/metering-device-values/">
   <soapenv:Header>
      <ISRequestHeader>
         <Date>2026-09-16T12:00:00.000+03:00</Date>
         <MessageGUID>c4a6b280-91bc-4e31-9f93-0123456789ab</MessageGUID>
      </ISRequestHeader>
   </soapenv:Header>
   <soapenv:Body>
      <dev:importMeteringDeviceValuesRequest>
         <dev:FIASHouseGuid>a8f5c321-1234-5678-90ab-cdef12345678</dev:FIASHouseGuid>
         <dev:MeteringDeviceValue>
            <dev:MeteringDeviceRootGUID>e92b3456-7890-abcd-ef01-234567890123</dev:MeteringDeviceRootGUID>
            <dev:CurrentValue>
               <dev:DateValue>2026-09-16</dev:DateValue>
               <dev:MeteringValue>00142.500</dev:MeteringValue>
               <dev:ReadingsSource>Информационная система абонента (Мобильное приложение)</dev:ReadingsSource>
            </dev:CurrentValue>
         </dev:MeteringDeviceValue>
      </dev:importMeteringDeviceValuesRequest>
   </soapenv:Body>
</soapenv:Envelope>
```
